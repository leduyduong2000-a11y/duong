# Thiệp cưới Duy Dương

Thiệp mời cưới online — ăn hỏi 09/01, tiệc mừng 10/01, đón dâu 11/01/2027.

- `index.html` — toàn bộ trang thiệp. Sửa thông tin ở khối `CONFIG` gần cuối file.
- `img/` — ảnh Sa Pa.
- `apps-script/Code.gs` — script gắn vào Google Sheet để nhận xác nhận của khách.

Link riêng cho từng khách: `?k=<mã>&to=<tên khách>` (tạo tự động từ menu 💌 Thiệp cưới trong Google Sheet).
